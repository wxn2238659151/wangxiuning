JavaScript 的两种定时器

setTimeout 延时执行一次　·　setInterval 每隔一段时间重复执行
--:--:--
一、两种定时器的区别

两者都属于 window 对象的方法，返回值都是一个数字编号（定时器 ID），需要通过这个 ID 来清除。

setTimeout：一次性定时器

在等待指定的毫秒数之后，只执行一次回调函数，执行完就自动结束。
写法：setTimeout(函数, 毫秒)
清除：clearTimeout(id)

setInterval：周期性定时器

每隔指定的毫秒数就重复执行回调函数，直到被清除为止。
写法：setInterval(函数, 毫秒)
清除：clearInterval(id)

五、参数与返回值
方法 参数 说明
setTimeout() 回调函数, 毫秒, 参数1… 延迟指定毫秒后执行一次回调；返回一个数字 ID，可用 clearTimeout(id) 取消。
setInterval() 回调函数, 毫秒, 参数1… 每隔指定毫秒执行一次回调，不断重复；返回一个数字 ID，可用 clearInterval(id) 停止。
clearTimeout() 定时器 ID 取消尚未执行的 setTimeout 任务，取消后回调永远不会再执行。
clearInterval() 定时器 ID 停止 setInterval 的循环触发。忘记清除会让定时器一直在后台跑，白白占用资源。
// 1. 延时执行一次：3 秒后弹出提示，期间可以取消 var wxn_timer = setTimeout(function () { alert("3 秒到了"); }, 3000); clearTimeout(wxn_timer); // 取消，回调不再执行 // 2. 周期性执行：每隔 1 秒让数字加 1，数到 5 就停下 var wxn_count = 0; var wxn_interval = setInterval(function () { wxn_count++; console.log("第 " + wxn_count + " 秒"); if (wxn_count === 5) { clearInterval(wxn_interval); // 到 5 次就停止，否则会一直跑下去 } }, 1000);
课堂小结：
  • setTimeout 只执行一次，setInterval 会一直重复，两者的第一个参数都是「函数」，第二个参数都是「毫秒」。
  • 两个方法都是异步的：代码写在这里，回调要等到时间到了才进入任务队列执行，所以后面同步的代码会先跑完。
  • 延迟时间写成 0 也不是立刻执行，只是尽快排进队列，仍然要等当前代码执行完。
  • 定时器一定要保存 ID 并记得清除；页面关闭前清除，可以避免回调操作已经被销毁的 DOM。
