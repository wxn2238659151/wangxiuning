1JSON 的六种数据类型

点击卡片查看说明

JSON（JavaScript Object Notation）只认这 6 种值：字符串、数字、布尔、null、对象、数组。 没有 undefined、没有函数、没有日期类型。

2五条语法红线

写错一条就解析失败

JSON 是"严格"的数据格式，浏览器里的 JSON.parse() 不会替你宽容任何一处违规。

✓
键名必须用双引号 正确：{"name":"王秀宁"}　错误：{name:"王秀宁"}
✓
字符串只能用双引号 单引号 'abc' 在 JSON 中非法，JS 对象里却合法。
✗
不能写注释 // 说明 与 /* 说明 */ 都会让解析报错。
✗
最后一项不能有逗号 {"a":1,"b":2,} 是非法尾逗号。
✗
不允许 undefined 与函数 {"fn":function(){}} 无法序列化，会被直接丢弃。
✓
最外层可以是对象或数组 { ... } 与 [ ... ] 都算合法 JSON 文本。

3JS 对象 ≠ JSON

长得像，规矩不同

JSON 是字符串，用来传输；JS 对象是内存里的数据结构，用来操作。两者靠 JSON.stringify() 与 JSON.parse() 互相转换。

JS 对象字面量（宽松）

const wxn_user = {
  name: '王秀宁',          // 键可不加引号
  age: 20,
  sayHi() { return 'hi'; } // 可以有函数
};
  • 键名可省略引号
  • 字符串可用单引号
  • 可以写注释、尾逗号
  • 可以放函数、undefined、Date

JSON 文本（严格）

{
  "name": "王秀宁",
  "age": 20,
  "tags": ["前端", "JSON"],
  "vip": true,
  "remark": null
}
  • 键名必须是双引号字符串
  • 只允许 6 种数据类型
  • 不能写注释、不能有尾逗号
  • 本质就是一串纯文本
