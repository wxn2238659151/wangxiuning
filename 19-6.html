流程图 Flowchart + 实体关系图 ER · 本地 Mermaid 渲染
智能客服系统 —— 咨询处理业务流程

展示用户一次咨询的完整链路：提问 → 预处理 → 意图识别 → 知识库检索 / 大模型生成 → 答案回复 → 满意度反馈，未解决时转人工并生成工单。 

flowchart TD
    A([用户发起咨询]) --> B[输入预处理
敏感词过滤 / 分词]
    B --> C{意图识别
NLU}
    C -->|常见问题| D[知识库检索
向量匹配 Top-K]
    C -->|业务办理| E[调用业务 API
查询订单 / 物流]
    C -->|闲聊| F[大模型生成回复]
    D --> G{置信度 ≥ 阈值?}
    G -->|是| H[组装标准答案]
    G -->|否| F
    E --> H2[模板化答案组装]
    F --> H
    H --> I[多渠道回复用户]
    H2 --> I
    I --> J{满意度评价}
    J -->|满意| K([会话结束 · 记录日志])
    J -->|不满意| L[转接人工客服]
    L --> M[创建工单跟进]
    M --> K
    K -.-> N[(会话数据库
沉淀语料 / 优化知识库)]
    N -.-> D

智能客服系统 —— 核心数据模型 ER 图

描述系统核心实体及其关系：一个用户可发起多个会话，一个会话包含多条消息； 知识条目归属于知识分类；未解决的问题生成工单，由客服人员处理。 

erDiagram
    USER ||--o{ SESSION : "发起"
    USER ||--o{ TICKET : "提交"
    SESSION ||--|{ MESSAGE : "包含"
    SESSION ||--o{ TICKET : "升级为"
    MESSAGE }o--|| INTENT : "识别为"
    MESSAGE ||--o| ANSWER : "命中"
    ANSWER }o--|| KNOWLEDGE_ITEM : "来源"
    KNOWLEDGE_ITEM }o--|| KNOWLEDGE_CATEGORY : "归属"
    TICKET }o--|| AGENT : "受理"
    AGENT }o--o{ KNOWLEDGE_ITEM : "维护"

    USER {
        bigint user_id PK "用户ID"
        string nickname "昵称"
        string phone "手机号"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "用户ID"
        string channel "渠道"
        datetime start_time "开始时间"
        datetime end_time "结束时间"
        tinyint satisfaction "满意度1-5"
    }
    MESSAGE {
        bigint message_id PK "消息ID"
        bigint session_id FK "会话ID"
        int role "角色 0用户 1系统"
        text content "消息内容"
        datetime send_time "发送时间"
    }
    INTENT {
        bigint intent_id PK "意图ID"
        string intent_name "意图名称"
        float threshold "命中阈值"
    }
    ANSWER {
        bigint answer_id PK "答案ID"
        bigint message_id FK "消息ID"
        float score "匹配分数"
        text content "答案内容"
    }
    KNOWLEDGE_ITEM {
        bigint kb_id PK "知识条目ID"
        bigint category_id FK "分类ID"
        string question "标准问题"
        text answer "标准答案"
        vector embedding "向量表示"
        int hit_count "命中次数"
    }
    KNOWLEDGE_CATEGORY {
        bigint category_id PK "分类ID"
        string category_name "分类名称"
    }
    TICKET {
        bigint ticket_id PK "工单ID"
        bigint session_id FK "会话ID"
        bigint user_id FK "用户ID"
        bigint agent_id FK "客服ID"
        string status "状态"
        datetime created_at "创建时间"
    }
    AGENT {
        bigint agent_id PK "客服ID"
        string agent_name "客服姓名"
        string group_name "技能组"
        tinyint online "是否在线"
    }
