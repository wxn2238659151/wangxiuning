JavaScript 第七种（第六种基础）类型：Symbol

王秀宁 · ES6 引入的新基础数据类型

一、JavaScript 的 7 种基础数据类型

二、Symbol 是什么？

Symbol 是一种唯一的、不可变的标识符，常用于给对象添加不会冲突的属性键。
它是继 Boolean / Null / Undefined / Number / String 之后的第六种基础类型（ES6）， 之后 ES2020 又新增了 BigInt 作为第七种。

三、演示 1：创建 Symbol 与唯一性

const wxn_s1 = Symbol();
const wxn_s2 = Symbol();
const wxn_s3 = Symbol("我的描述");

console.log(typeof wxn_s1);     // "symbol"
console.log(wxn_s1 === wxn_s2); // false —— 每个 Symbol 都唯一
console.log(wxn_s3.description); // "我的描述"

四、演示 2：全局 Symbol 注册表（Symbol.for / Symbol.keyFor）

const wxn_a = Symbol.for("wxn_key"); // 不存在就创建，存在就返回已有的
const wxn_b = Symbol.for("wxn_key");
console.log(wxn_a === wxn_b);          // true —— 同一个 key 对应同一个 Symbol

console.log(Symbol.keyFor(wxn_a));      // "wxn_key"
console.log(Symbol.keyFor(Symbol()));   // undefined —— 未注册的查不到

五、演示 3：Symbol 作为对象属性键

const wxn_obj = { name: "测试" };
const wxn_secret = Symbol("secret");
wxn_obj[wxn_secret] = "我不会被 for...in 枚举";

console.log(Object.keys(wxn_obj));          // ["name"] —— Symbol 键不可枚举
console.log(Object.getOwnPropertySymbols(wxn_obj)); // [Symbol(secret)]

六、演示 4：内置 Well-known Symbol（Symbol.iterator）

const wxn_arr = [10, 20, 30];
const wxn_iter = wxn_arr[Symbol.iterator]();
console.log(wxn_iter.next()); // {value: 10, done: false}
console.log(wxn_iter.next()); // {value: 20, done: false}
console.log(wxn_iter.next()); // {value: 30, done: false}
console.log(wxn_iter.next()); // {value: undefined, done: true}

七、小结

✅ Symbol() 创建唯一值，每次调用都不相同
✅ Symbol("描述") 的描述仅用于调试，不影响唯一性
✅ Symbol.for("key") 跨文件共享同一个 Symbol
✅ Symbol 键不会被 for...in / Object.keys 枚举
✅ 常用于：对象私有属性、常量枚举、自定义迭代器
