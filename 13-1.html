CSS 变量（自定义属性）

使用 :root 定义全局变量，通过 var() 引用，实现主题切换与代码复用

基本用法

CSS 变量以 -- 开头定义，通过 var() 函数引用。在 :root 中定义可全局使用。

/* 定义变量 */ :root { --wang_primary: #58a6ff; --wang_radius: 12px; } /* 使用变量 */ .wang_card { border-radius: var(--wang_radius); background: var(--wang_primary); }
